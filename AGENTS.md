# Русь: Эпоха войн

Проект Godot 4.7.2. F5 и `Запустить.cmd` открывают стратегическую карту. Для отдельного боя есть `Запустить тактический бой.cmd`.

## Как работать с контекстом

1. Выбери модуль по таблице. Если файл уже известен из запроса или предыдущего шага, начни с него. Ищи нужный символ или текст ошибки через `rg -n` в выбранном файле и читай найденный участок с соседними строками.
2. Открывай соседний модуль, только если для задачи нужно проверить конкретный вызов, структуру данных, сигнал, сцену или причину ошибки. Если точка входа неизвестна, начни с поиска по имени файла или символу в ближайшем каталоге.
3. Используй уже собранный контекст в продолжении задачи. Перечитывай только изменившиеся участки или код, необходимый для нового вопроса.
4. Ограничивай правки и проверки затронутым поведением. При изменении общего интерфейса проверь его непосредственных вызывающих.

По умолчанию пропускай `.godot/`, `build/`, `art/`, бинарные ассеты и логи. Открывай `README.txt`, когда нужна справка для игрока или автора ассетов.

## Особенности запуска и проверки

- Карта запускается без ресурсов тактики. Путь к `scenes/battlefield.tscn` хранится строкой, загрузка начинается при столкновении. Во время боя карта остаётся в отдельном выключенном viewport. Тактика использует `SceneTree.current_scene` для доступа к службам боя.
- Сохраняй отдельный запуск обычного боя. Для тактических потерь сопоставляй отряды по их ID, а не по названию или типу.
- Боевые сцены начинают на паузе. Проверки, которым нужна симуляция, явно возобновляют её через `set_battle_paused(false)`.
- Для проверки запуска используй локальный `Godot_v4.7.2-stable_win64.exe` с `--headless --path . --quit-after 5` и путём к изменённой сцене. Проверки из `tools/` запускай выборочно. Разовые сценарии и снимки храни в `build/`, временные скрипты после проверки убирай.
